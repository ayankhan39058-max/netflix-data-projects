# Netflix Data Analysis

Exploratory data analysis (EDA) of Netflix movie data using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
`mymoviedb(3).csv` with columns: Release_Date, Title, Overview, Popularity, Vote_Count, Vote_Average, Original_Language, Genre, Poster_Url.

## What I Did
- Loaded and cleaned the data
- Explored popularity, ratings and genres
- Created charts to find trends

## How to Run
1. Download this repository
2. Install the libraries: `pip install numpy pandas matplotlib seaborn`
3. Open `Netflix Data Analysis.ipynb` in Jupyter Notebook
4. Run all cells
